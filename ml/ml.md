第X章 智能分析与预测模块设计
├─ X.1 模块总体架构
│   ├─ 模型管线图：数据采集→预处理→特征工程→模型训练→评估→部署调用
│   └─ 技术栈：Python(Scikit-learn, Statsmodels, Pandas), 模型持久化(joblib/pickle)
├─ X.2 销售预测（UC-02）
│   ├─ 业务目标：预测未来7天/30天各商品日销量
│   ├─ 输入数据：sales_record(按日聚合销量) JOIN product(取category_id)
│   ├─ 特征工程（共7维特征）
│   │   ├─ 时间特征：dayofweek(0-6), month(1-12), day(1-31), is_weekend(0/1)
│   │   ├─ 滞后特征：lag_1(前一天销量), rolling_mean_7(前7天均值)
│   │   │   └─ 说明：lag_7/lag_30 在递归预测场景下无法更新，已移除
│   │   └─ 商品特征：category_id（品类ID，让模型区分不同品类的销售规律）
│   ├─ 基线模型：线性回归（普通最小二乘）
│   │   ├─ 目标变量：total_qty（日销量件数）
│   │   └─ 评估指标：MAE, RMSE, MAPE
│   ├─ 进阶模型：ARIMA / Prophet / LightGBM（选1-2，标注P1迭代）
│   └─ 输出接口：模型预测值写入数据库 predicted_sales 表，由后端API调用
├─ X.3 库存预测与补货建议（UC-03）
│   ├─ 业务目标：基于销售预测 + 安全库存模型，计算建议补货量
│   ├─ 算法逻辑
│   │   ├─ 未来N天总需求 = Σ每日预测销量
│   │   ├─ 安全库存 = z × √(L) × σ_daily_demand
│   │   └─ 建议补货量 = 未来需求 + 安全库存 - 当前库存 - 在途库存
│   └─ 模型依赖：销售预测模块的输出
├─ X.4 异常检测（UC-08）
│   ├─ 业务目标：识别销量骤降、库存积压、价格异常
│   ├─ 方案一（规则引擎，P0首选）
│   │   ├─ 销量异常：当前销量 < (7天移动平均 - 2×标准差)
│   │   ├─ 库存积压：当前库存 > 滚动30天日均销量 × 45
│   │   └─ 阈值可配置
│   ├─ 方案二（Isolation Forest 无监督，P1）
│   │   └─ 特征：销量、库存、价格变化率、转化率
│   └─ 输出：异常事件写入 alert 表，并触达预警页面
├─ X.5 用户画像计算（UC-04, P1）
│   ├─ RFM模型：最近购买天数、购买频次、消费金额(或购买件数)
│   └─ 客群分层（高价值/流失预警等）
└─ X.6 模型更新策略
    ├─ 冷启动：初期使用全局商品平均销量填充
    └─ 更新频率：每凌晨2点重训练，增量数据追加
