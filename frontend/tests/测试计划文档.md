> **版本**：v1.0

## 1. 测试概述

### 1.1 测试目标

通过系统化的功能测试、性能测试和集成测试，确保系统满足需求分析文档中定义的 P0/P1 用例的验收标准，保证系统能够在课堂演示中稳定运行。

### 1.2 测试范围

| 范围 | 说明 |
|------|------|
| **P0 用例** | UC-01 查询、UC-02 预测、UC-03 库存、UC-08 预警、UC-09 报表 |
| **P1 用例** | UC-04 画像、UC-07 营销、UC-10 权限 |
| **非功能测试** | 登录认证、页面加载性能、响应时间 |
| **边界测试** | 空数据、异常输入、大并发 |

### 1.3 测试策略

```
测试金字塔：
          ┌──────┐
          │  E2E │  ← 关键流程（登录→查询→预测→预警）
         ┌┴──────┴┐
         │ 集成测试 │  ← API对接（前端↔后端、后端↔ML）
        ┌┴────────┴┐
        │ 单元测试  │  ← 后端函数、ML模型函数
       ┌┴──────────┴┐
       │ 手动探索测试 │  ← UI兼容、边界场景
       └────────────┘
```

## 5. 测试流程

### 5.1 测试执行流程

```
1. 准备测试环境
   ├── 启动 MySQL 数据库
   ├── 导入测试数据（init.sql）
   ├── 启动后端（python app.py）
   ├── 启动前端（npm run dev）
   └── 打开浏览器访问 http://localhost:5173

2. 执行测试用例
   ├── 按优先级从高到低执行
   ├── P0 用例必须全部通过
   ├── P1 用例至少 80% 通过
   └── 记录测试结果

3. Bug 跟踪
   ├── 发现 Bug → 记录到 Bug 日志
   ├── 标记严重程度（Critical/Major/Minor）
   └── 通知对应负责人修复
```

### 5.2 Bug 日志模板

| 编号 | 日期 | 模块 | 测试用例 | 问题描述 | 严重程度 | 状态 | 负责人 |
