## 2. 部署步骤

### 2.1 快速部署（推荐 - Docker Compose）

如果项目提供了 Docker Compose 配置，可以使用以下命令一键部署：

```bash
# 1. 克隆项目
git clone https://github.com/Qian-YiChen/ecommerce-bi-system.git
cd ecommerce-bi-system

# 2. 启动所有服务
docker-compose up -d

# 3. 查看服务状态
docker-compose ps
```

### 2.2 手动部署（开发环境）

#### 步骤 1：克隆代码

```bash
git clone https://github.com/Qian-YiChen/ecommerce-bi-system.git
cd ecommerce-bi-system
```

#### 步骤 2：数据库部署

```bash
# 2.1 登录 MySQL
mysql -u root -p

# 2.2 创建数据库
CREATE DATABASE ecommerce_bi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 2.3 导入表结构
mysql -u root -p ecommerce_bi < database/init.sql

# 2.4 导入测试数据（可选）
mysql -u root -p ecommerce_bi < frontend/tests/test_data.sql
```

#### 步骤 3：后端部署

```bash
# 3.1 创建虚拟环境
cd backend
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 3.2 安装依赖
pip install -r requirements.txt

# 3.3 配置数据库连接
# 编辑 backend/config.py 中的 MySQL 连接参数：
#   MYSQL_HOST = 'localhost'
#   MYSQL_PORT = 3306
#   MYSQL_USER = 'root'
#   MYSQL_PASSWORD = 'your_password'
#   MYSQL_DATABASE = 'ecommerce_bi'

# 3.4 启动后端服务
python app.py
# 服务启动在 http://localhost:5000
```

#### 步骤 4：前端部署

```bash
# 4.1 进入前端目录
cd frontend

# 4.2 安装依赖
npm install

# 4.3 开发模式启动
npm run dev
# 服务启动在 http://localhost:5173

# 4.4 （可选）生产模式构建
npm run build
# 构建产物在 dist/ 目录，可部署到 nginx 等 Web 服务器

# 4.5 （可选）使用 nginx 部署生产版本
# 将 dist/ 目录下的文件复制到 nginx 的 html 目录
sudo cp -r dist/* /var/www/html/
sudo systemctl restart nginx
```

#### 步骤 5：ML 模型服务

```bash
# 5.1 进入 ML 目录
cd ml

# 5.2 安装依赖（如果已有后端虚拟环境，可复用）
pip install -r ../backend/requirements.txt
pip install scikit-learn statsmodels pandas

# 5.3 运行模型训练/预测
python ml_pipeline.py
```

## 3. 配置说明

### 3.1 后端配置

编辑 `backend/config.py`：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `MYSQL_HOST` | MySQL 主机地址 | localhost |
| `MYSQL_PORT` | MySQL 端口 | 3306 |
| `MYSQL_USER` | MySQL 用户名 | root |
| `MYSQL_PASSWORD` | MySQL 密码 | （必填） |
| `MYSQL_DATABASE` | 数据库名 | ecommerce_bi |
| `JWT_SECRET` | JWT 签名密钥 | （自动生成） |
| `JWT_EXPIRATION_HOURS` | Token 过期时间 | 2 |

### 3.2 前端配置

编辑 `frontend/src/api/index.js`，修改 API 基础地址：

```javascript
const api = axios.create({
  baseURL: 'http://localhost:5000/api',  // 修改为后端实际地址
  timeout: 15000,
})
```

### 3.3 MySQL 配置注意

- 数据库必须使用 `utf8mb4` 字符集，以支持中文和特殊字符
- 建议将 MySQL 的 `max_allowed_packet` 设置为 64MB 以上，以支持大数据量导入
- 如果使用远程数据库，确保 MySQL 用户有远程访问权限

## 5. 常见问题排查

### 5.1 后端无法启动

```
问题：启动后端时 ModuleNotFoundError
解决：检查是否在虚拟环境中，pip install -r requirements.txt 是否完成

问题：连接 MySQL 报错
解决：检查 config.py 中的数据库配置是否正确
解决：确认 MySQL 服务是否正常运行
解决：确认数据库 ecommerce_bi 是否已创建
```

### 5.2 前端无法启动

```
问题：npm install 失败
解决：尝试删除 node_modules 目录后重试
      rm -rf node_modules && npm install

问题：页面白屏或 404
解决：检查是否在 frontend 目录下执行 npm run dev
解决：检查浏览器控制台是否有跨域报错
```

### 5.3 登录失败

```
问题：登录提示"用户名或密码错误"
解决：确认 init.sql 和 test_data.sql 是否已导入
解决：检查后端 config.py 的数据库连接是否正确
解决：查看后端终端输出是否有 SQL 错误日志
```

### 5.4 跨域问题

如果前端和后端运行在不同端口，Flask 后端需配置 CORS。`backend/app.py` 中已包括：

```python
from flask_cors import CORS
CORS(app)
```

如果不生效，检查是否安装了 `flask-cors`：

```bash
pip install flask-cors
```
