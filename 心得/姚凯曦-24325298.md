在这次《软件工程》课程实践中，我负责前端管理页面的开发、系统测试和相关文档的编写。通过这次项目，我对软件工程全流程有了更深入的理解。

前端开发方面，我使用 Vue 3 + Element Plus 实现了登录页、用户管理页、预警展示页和数据源配置页。登录页对接了后端的 JWT 认证流程，实现了表单校验、Token 存储和自动跳转；预警中心支持按严重程度和状态筛选，以及处理和忽略操作；用户管理页实现了用户的增删改查和角色权限控制。为了让前端能够独立演示，我还设计了演示模式，使用 Mock 数据展示所有页面效果，无需后端即可运行。

测试方面，我编写了测试计划文档，覆盖了认证、预警、用户管理等六大模块共 30 多个测试用例。后端 96 项集成测试全部通过，验证了登录注册、JWT 鉴权、预测 API 和预警规则的完整链路。测试过程中我意识到，完善的测试用例设计对于保证软件质量至关重要。

文档方面，我完成了测试计划、测试报告和部署操作说明三份文档，确保系统的可复现性和可维护性。

通过这次团队协作，我体会到了接口约定、进度同步和分工配合的重要性。这次实践不仅提升了我的技术能力，也让我对工程化开发有了更全面的认识。
