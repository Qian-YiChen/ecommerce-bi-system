# UML 图清单

本目录提供一套可直接修改和渲染的 `PlantUML` 图源码，对应项目剩余任务清单中的必做 UML 图与甘特图前置素材。

## 必做 UML 图

- `01-usecase.puml`：用例图
- `02-domain-class.puml`：领域类图
- `03-state-alert-rule.puml`：AlertRule 状态图
- `04-state-order.puml`：Order 状态图
- `05-er-diagram.puml`：ER 图
- `06-component-diagram.puml`：构件图
- `07-activity-login.puml`：活动图 - 登录认证流程
- `08-activity-query.puml`：活动图 - 销售数据查询流程
- `09-activity-alert-scan.puml`：活动图 - 预警扫描流程
- `10-sequence-query.puml`：顺序图 - 数据查询
- `11-sequence-predict.puml`：顺序图 - 销售预测
- `12-sequence-alert.puml`：顺序图 - 异常预警

## 使用建议

如果你想快速出图：

1. 把 `.puml` 文件复制到任意支持 PlantUML 的网站或插件中渲染
2. 导出为 `png` 或 `svg`
3. 若老师更偏好 Draw.io 风格，可把这里的结构当成草稿，在 Draw.io 中照着重画

## 备注

- 这些图基于当前仓库代码、README 和文档内容生成，足够支撑课程作业提交
- 个别细节如字段数量、箭头样式、颜色可按你们老师偏好再微调
