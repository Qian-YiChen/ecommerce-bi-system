- **Python 环境**：`D:\Anaconda\python.exe`（Python 3.13.9）
- **所有数据库操作函数**返回 `Optional` 或 `List`，不直接抛异常（异常由调用方统一处理）

> 注：2026-06-20 闫维岳↔姚凯曦交换分工，姚凯曦现负责前端核心页面

### 4.1 统一 API 响应格式

所有后端 API 返回的 JSON 遵循统一格式：

```json
// 成功
{
  "success": true,
  "data": { ... },       // 具体数据
  "message": "操作成功"
}

// 失败
{
  "success": false,
  "data": null,
  "error": "错误描述",
  "code": "ERROR_CODE"   // 前端据此处理不同错误类型
}
```

### 4.2 认证 Token 传递

前端在每次请求的 Header 中携带：
```
Authorization: Bearer <jwt_token>
```

Token 过期（401）时前端自动跳转登录页。

### 4.3 严辰乐负责的 API（供姚凯曦参考）

| 方法 | 路径 | 说明 | 需要 Token |
|------|------|------|-----------|
| POST | /api/auth/login | 登录 | 否 |
| POST | /api/auth/register | 注册用户 | 是（admin） |
| GET | /api/auth/me | 当前用户信息 | 是 |
| GET | /api/predict/sales | 获取最新销售预测结果 | 是 |
| GET | /api/predict/stock | 获取补货建议 | 是 |
| POST | /api/alert/scan | 手动触发异常扫描 | 是 |
| GET | /api/alert/rules | 获取预警规则列表 | 是 |
| POST | /api/alert/rules | 创建预警规则 | 是（admin） |
| GET | /api/alert/logs | 获取预警日志 | 是 |
| PUT | /api/alert/logs/{id}/resolve | 标记预警已处理 | 是 |
